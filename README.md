# Andrea Rocca - Personal Portfolio

This is my personal academic portfolio website, showcasing my research in mathematics, specifically in regularity theory of PDEs via variational methods.

## Features

- **About Me**: Academic background and research interests
- **Publications**: Research papers and preprints
- **Projects**: Research projects and visualizations
- **Gallery**: Photos and research images
- **Teaching**: Academic activities and teaching experience

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- MathJax (for mathematical notation)
- Font Awesome (icons)

## Research Interests

- Regularity theory in PDEs
- Variational methods
- Sharp functional inequalities
- Shape optimization
- Free boundary problems
- Nonlinear analysis

## Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. To deploy to GitHub Pages:
   - Ensure the repository is named `yourusername.github.io`
   - Push to the `main` branch
   - Your site will be available at `https://yourusername.github.io`

## Customization

- Edit `index.html` to update content
- Modify `css/style.css` to change colors and styling
- Add your photos to the `img/gallery/` folder
- Update links in the contact section
